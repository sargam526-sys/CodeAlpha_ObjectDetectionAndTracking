# CodeAlpha - Object Detection and Tracking (AI Task 4)

## 📌 Overview
An AI computer vision project implementing real-time object detection and multi-object tracking (MOT) using a pre-trained **YOLOv8** model and built-in tracking algorithms (ByteTrack/SORT).

## 🚀 Features
- **Object Detection:** Identifies multiple classes (people, vehicles, objects) per frame.
- **Object Tracking:** Assigns and maintains unique persistent IDs across video sequences.
- **Pre-trained Weights:** Leverages YOLOv8 nano architecture for fast inference.

## 🛠️ Tech Stack
- Python 3
- Ultralytics YOLOv8
- OpenCV
- Google Colab
